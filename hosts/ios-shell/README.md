# iOS Prebuilt Host Shell (`hosts/ios-shell`)

This directory provides a standalone zero-Xcode-project iOS Simulator runner and an embeddable iOS
component view over **`libnve_runtime`** (built for `aarch64-apple-ios-sim` by `run-simulator.sh`),
sharing `hosts/apple-common` with the macOS shell.

## Quick Start: One-Command iOS Simulator Launcher (`run-simulator.sh`)

Build, sign, install, and launch any NVE Rust app (`nve-studio-workspace`, `nve-example-kitchen-sink`, or any crate exporting `nve_get_interface`) directly in the iOS Simulator — no `.xcodeproj` or `xcodebuild` required:

```bash
# Default: build & launch nve-studio-workspace in the iOS Simulator
./hosts/ios-shell/run-simulator.sh

# Launch the interactive Kitchen Sink gallery
./hosts/ios-shell/run-simulator.sh nve-example-kitchen-sink

# Build the signed NveIosShell.app bundle only (no Simulator boot/install)
./hosts/ios-shell/run-simulator.sh nve-example-kitchen-sink --build-only

# Headless launch + screenshot capture on a specific Simulator
./hosts/ios-shell/run-simulator.sh nve-example-kitchen-sink \
  --headless \
  --device "iPhone 16 Pro" \
  --screenshot /tmp/nve-ios.png
```

Prerequisites:

- Xcode Command Line Tools / iOS Simulator SDK (`xcrun --sdk iphonesimulator`)
- Rust iOS Simulator target: `rustup target add aarch64-apple-ios-sim`

At runtime `main.mm` mounts `RCTNveComponentView` pinned inside the root view controller's `safeAreaLayoutGuide` (updating across rotation and resize) and loads `NveIosShell.app/libnve_app.dylib` (overridable via the `NVE_APP_DYLIB` environment variable).

Dev loop: `nve dev` hot patches (`NVP1`) go to `-[NveAppleComponentHost applyHotPatch:]`
(`apply_hot_patch`); Tier-2 rebuilt dylibs go to `-reloadNveDylibAtPath:error:` (state kept via
`snapshot_state` / `restore_state`); thin-client pairing uses `--pair-connect` / `NVE_PAIR_*`.

## Embeddable React Native Fabric Component (`RCTNveComponentView.h` / `RCTNveComponentView.mm`)

Mounts any NVE Rust component (`nve_get_interface`) directly inside an existing React Native iOS app as a native Fabric component view:

- Subclasses `RCTViewComponentView` when compiled with `-DNVE_WITH_RN_FABRIC=1` (and falls back cleanly to `UIView` for standalone iOS SDK checks).
- Owns an `NveAppleComponentHost` (`nve::host::RuntimeSession`): RN props (`-applyPropsDictionary:` -> `set_props`), native UIKit views realized from the runtime scene's core tables, touches / text / focus / scroll back into the app (`dispatch_events`), and outbound events (`drain_emitted_events` -> `-handleNveEvent:payload:` / `onNveEvent` / `delegate`).
- Subclasses generated by `nve codegen export --target rn` override `-defaultNveGetInterface` and `-handleNveEvent:payload:` to wire typed Fabric `Props` and `EventEmitter` classes verbatim.

# Benchmarks & Profiling

Performance is continuously verified against `benchmarks/baseline.json` with a default **15% regression tolerance** (`25%` for sub-50 ns microbenchmarks) across Rust Criterion (`packages/tools/bench`). The C++ `SceneReader` read path (open / dirty / full read) is measured separately by `nve_host_cxx_bench --json` (`packages/core/host-cxx`), which feeds the same regression script.

All numbers below are real measured medians from `benchmarks/baseline.json` recorded on **Apple Silicon (`arm64`, Darwin, 20 cores)**.

## Running Benchmarks & Capturing Traces

```bash title="Run Criterion, C++ SceneReader benchmarks, and Perfetto trace capture"
# 1. Full Rust Criterion suite
cargo bench -p nve-bench

# 2. Multi-backend CLI bench with Perfetto / Chrome trace export
cargo nve bench --rows 1000 --frames 50 --trace /tmp/nve.perfetto.json

# 3. Release C++20 SceneReader benchmark (JSON output)
cmake -S packages/core/host-cxx -B packages/core/host-cxx/build -G Ninja \
  -DNVE_HOST_CXX_BUILD_BENCH=ON -DCMAKE_BUILD_TYPE=Release
cmake --build packages/core/host-cxx/build
./packages/core/host-cxx/build/nve_host_cxx_bench --json
```

Open `/tmp/nve.perfetto.json` in `https://ui.perfetto.dev` or `chrome://tracing` to inspect per-frame `reconcile_us`, `encode_us`, `decode_us`, `layout_us`, `diff_us`, and `mount_us` spans.

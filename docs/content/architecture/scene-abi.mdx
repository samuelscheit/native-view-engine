# 64-Byte Scene ABI

After a backend decodes a `CommandBuffer` and computes Flexbox layout, native hosts (Apple CoreGraphics/AppKit/UIKit, Win32/Direct2D, Qt Quick `QSGNode`, Android `DirectByteBuffer`, Jetpack Compose, SwiftUI, Flutter Impeller, and Web) read the resolved scene straight from shared memory with **zero decoding and zero per-node allocations**.

## `NveRenderNode`: Exactly One CPU Cache Line

`NveRenderNode` (`packages/core/abi/src/scene/types.rs`) is `#[repr(C, align(64))]` and strictly verified at compile time to occupy **64 bytes** (`NVE_RENDER_NODE_SIZE == 64`, `NVE_RENDER_NODE_ALIGN == 64`). Every field offset is locked by `const` `offset_of!` assertions in Rust and `_Static_assert(offsetof(...))` in `nve_abi.generated.h` (`packages/core/host-cxx/include/nve/generated/`).

| Offset | Size | Field | Type | Description |

## `NveSceneView` & Incremental Dirty Diffing

`NveSceneView` bundles flat read-only pointers to five contiguous slabs plus a compile-time schema hash:

```c title="nve_abi.generated.h (excerpt)" highlight="2,5-6,10-14"
typedef struct NveSceneView {
  uint64_t schema_hash;          // NVE_SCENE_SCHEMA_HASH (compile-time 64-bit XXH64)
  uint64_t frame_id;
  uint32_t node_count;
  uint32_t dirty_count;          // indices into nodes[] that changed this frame
  uint32_t removed_count;        // node_ids deleted since previous frame
  uint32_t text_slab_len;
  uint32_t children_slab_len;
  uint32_t _pad;
  const NveRenderNode* nodes;
  const uint8_t*       text_slab;
  const uint32_t*      children_slab;
  const uint32_t*      dirty_indices;
  const uint32_t*      removed_ids;
} NveSceneView;
```

### Zero-Decode Host Reads

Instead of re-walking the entire tree every frame, hosts iterate only `dirty_indices[0..dirty_count]` and tear down `removed_ids[0..removed_count]`:

- Reading 3 dirty nodes out of 1,000 takes **24.82 ns** (`rust::abi/scene/scene_view_read_dirty_3_of_1000`).
- Publishing 10 dirty nodes on a 1,000-node C++20 scene takes **7.54 µs** (`cxx::scene_view_publish_10_on_1000`).
- On Android JNI (`hosts/android-shell/NveAndroidSurfaceJni.cpp`), `CachedDirectBuffer` wraps each slab in a persistent `GlobalRef` `java.nio.ByteBuffer` (`NewDirectByteBuffer`), re-creating the JNI reference **only** when a slab pointer or capacity grows — achieving zero GC allocations per frame in Java (`dev.nve.host.SceneReader` with the generated `dev.nve.host.generated.NveAbi` offsets) and Jetpack Compose (`NveSceneBuffer.kt`).

### Compile-Time Schema Hash Lock

`NVE_SCENE_SCHEMA_HASH` is computed at compile time via XXH64 over every field name, type, and byte offset of `NveRenderNode`, `NveSceneView`, and `NveNodeMeta`. Every static host `SceneReader` (`packages/core/host-{cxx,swift,java,dart,ts}`) verifies `view.schema_hash` against the generated `NVE_SCENE_SCHEMA_HASH` before dereferencing a single node, making ABI drift fail fast and deterministically.

## Zero-Copy `text_slab` & `NVE_DRAW1`

All UTF-8 node strings live packed inside `text_slab`. A host slices `&text_slab[node.text_offset .. node.text_offset + node.text_len]` directly with zero string allocation.

For `NVE_NODE_KIND_SKIA_CANVAS` (`kind == 7`) nodes, vector drawing operations use the **`NVE_DRAW1`** binary draw-list IR (`packages/core/components/src/canvas_ir/`):

- 15-byte header: `b"NVE_DRAW1"` (9 B) + `version: u16 (1)` + `op_count: u32` (capped at `65,536`)
- 8 compact opcodes: `Clear`, `FillRect`, `FillRoundedRect`, `FillCircle`, `StrokeLine`, `StrokePolyline`, `ClipRect`, `RestoreClip`
- Transported natively inside `RawPropValue::Bytes` (or `nve-draw1;b64,` when passed via RSX string attributes). See the [Vector Canvas (`NVE_DRAW1`) Guide](/guides/canvas-draw1).

## Auxiliary Dirty Metadata Slab (`NveNodeMeta` + `meta_blob`)

Keep `NveRenderNode` strictly at 64 bytes by moving sparse, variable-length per-node metadata (accessibility labels/roles/hints, ARIA states, image URIs/resize modes, `TextInput` placeholders/flags, and `NVE_DRAW1` draw lists) into fixed-stride 64-byte `NveNodeMeta` records (`#[repr(C)]`, locked by `NVE_NODE_META_SIZE == 64`) indexing into a flat companion `meta_blob` slab (`hosts/android-shell/NveAndroidMetadataPacker.cpp`, `hosts/compose-kit`).

- Packed **only** for dirty nodes that actually carry metadata — typical frames touch only a handful of nodes.
- Uses the same `CachedDirectBuffer` zero-copy `DirectByteBuffer` mechanism over JNI so Android TalkBack (`AccessibilityNodeProvider`) and Jetpack Compose `Modifier.semantics` stay synchronized at 120fps without allocating per-node Java/Kotlin objects or parsing custom TLV streams.

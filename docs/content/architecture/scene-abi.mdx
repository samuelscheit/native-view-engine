# Scene ABI

Native hosts (Apple AppKit/UIKit, Win32/Direct2D, Qt, GTK, Android `DirectByteBuffer`, Jetpack Compose, SwiftUI, Flutter, React Native components) read the resolved scene straight from `libnve_runtime` memory with **zero decoding and zero per-node allocations**. There is exactly **one** scene ABI: `NveSceneView` (`packages/core/abi/src/runtime/mod.rs`). The runtime fills it from the live `NodeStore` slabs; nothing is copied or re-encoded for the host.

## `NveSceneView`

`NveSceneView` bundles scalar counters and borrowed read-only pointers into `NodeStore` slabs. The runtime stamps `schema_hash` with `NVE_RUNTIME_SCHEMA_HASH`, the compile-time XXH64 over every field name, type, and byte offset of the runtime ABI records.

```c title="nve_runtime_abi.generated.h (excerpt)"
typedef struct NveSceneView {
  uint64_t schema_hash;            // NVE_RUNTIME_SCHEMA_HASH
  uint64_t frame_id;               // monotonic frame counter
  uint32_t node_capacity;          // slots in rows[] / rects[]; slot 0 is the reserved null
  uint32_t dirty_count;
  uint32_t removed_count;
  uint32_t text_slab_len;          // bytes
  uint32_t children_slab_len;      // u32 entries
  uint32_t table_count;
  uint32_t scroll_count;
  uint32_t scene_epoch;            // bumped when the runtime discards its scene
  uint32_t dirty_resource_count;
  uint32_t moved_count;
  const NveNodeRow*      rows;
  const NveLayoutRect*   rects;
  const uint8_t*         text_slab;
  const uint32_t*        children_slab;
  const uint32_t*        dirty_indices;
  const uint32_t*        removed_ids;
  const NveTableView*    tables;
  const NveScrollOffset* scroll_offsets;
  const uint32_t*        dirty_resources;
  const uint32_t*        moved_indices;
} NveSceneView;
```

### Acquire / release

Hosts obtain a view with `scene_acquire` from the `NveRuntimeApi` vtable (`nve_runtime_get_interface`) and must call `scene_release` when done. `scene_acquire` is callable from any thread and returns `BUSY` while a write is in progress; every pointer in the view (and `resource_payload` bytes) is borrowed until `scene_release`.

### `NveNodeRow`: 32 bytes per node

`rows[i]` is a 32-byte `#[repr(C)]` header (`NVE_NODE_ROW_SIZE == 32`) indexed by `NodeIndex`; offsets are locked by `offset_of!` in Rust and `static_assert(offsetof(...))` in the generated headers.

| Offset | Size | Field | Description |
| :--- | :--- | :--- | :--- |
| `0` | 16 B | `table_set` | 128-bit attached-table bitset as four little-endian `u32` words |
| `16` | 4 B | `parent` | Parent `NodeId` (`0` = root / detached) |
| `20` | 4 B | `child_off` | Element offset into `children_slab` |
| `24` | 4 B | `child_len` | Number of child `NodeId`s in `children_slab` |
| `28` | 1 B | `generation` | Slot generation (`1..=255`) |
| `29` | 1 B | `primary_slot` | Highest-priority realizing `TableSlot` (`0xFF` = plain container) |
| `30` | 1 B | `effects` | `effect::*` bits dirtied during the latest frame |
| `31` | 1 B | `flags` | `NVE_NODE_ROW_FLAG_LIVE` = bit 0 |

Visual and semantic properties (colors, text, image, accessibility, ...) live in typed word tables attached to the node (`table_set`), exposed through `tables` and the generated foreign table getters, not in the row.

### `NveLayoutRect`: 16 bytes per node

`rects[i]` is `{ f32 x, y, width, height }` (`NVE_LAYOUT_RECT_SIZE == 16`) at the same index as `rows[i]`, in absolute surface-space logical points.

### Incremental indices

Instead of re-walking the tree, hosts consume four delta lists:

- `dirty_indices[0..dirty_count]`: live node indices whose content changed this frame (created, row/parent/table/child list changed). A dirty node's rect may have changed too.
- `moved_indices[0..moved_count]`: live nodes **not** in `dirty_indices` whose box relative to their parent changed; hosts re-apply only position and size.
- `removed_ids[0..removed_count]`: raw `NodeId`s removed this frame.
- `dirty_resources[0..dirty_resource_count]`: strictly ascending resource ids (images, draw lists) (re)defined this frame. Host caches keyed by resource id MUST drop these entries.

`scene_epoch` is bumped whenever the runtime discards its scene (app attach / swap / detach, pairing connect / disconnect, keyframe or wire-error reset). All node ids, resource ids, and host caches from an earlier epoch are stale.

`scroll_offsets[0..scroll_count]` (`NveScrollOffset { node_id, x, y }`, sorted by `node_id`) carries per-container scroll shifts; absent containers have zero shift.

## Per-language `SceneReader`

Every language has exactly one reader, named `SceneReader`, that validates `schema_hash` against the generated `NVE_RUNTIME_SCHEMA_HASH` before dereferencing any row, so ABI drift fails fast and deterministically:

| Language | Reader |
| :--- | :--- |
| C++ | `nve::host::SceneReader` (`packages/core/host-cxx/include/nve/host/scene_reader.hpp`) |
| Swift | `SceneReader` (`packages/core/host-swift`) |
| Java / Kotlin | `dev.nve.host.SceneReader` (`packages/core/host-java`) over persistent `DirectByteBuffer` views |
| Dart | `SceneReader` (`packages/core/host-dart`) |
| TypeScript | `SceneReader` (`packages/core/host-ts`), reading wasm32 linear memory via the generated `NVE_SCENE_LAYOUT_WASM32` |

All field offsets come from generated bindings (`cargo run --locked -p nve-cli -- codegen abi`); nothing is hard-coded in the readers. On Android, `NveAndroidSurfaceJni.cpp` wraps each slab in a persistent `GlobalRef` `java.nio.ByteBuffer` and re-creates it only when a slab pointer or capacity grows, giving zero GC allocations per frame.

## Zero-Copy `text_slab` & Flat `DrawList`

All UTF-8 node strings live packed inside `text_slab`. A host slices `&text_slab[node.text_offset .. node.text_offset + node.text_len]` directly with zero string allocation.

For `nve.canvas` nodes, vector drawing operations use the flat 4-byte-aligned **`nve.res.draw_list`** `FlatResource` (`packages/modules/canvas/src/flat.rs`):

- 4-byte word header (`u32 op_count`, capped at `65,536`) followed by `u32` opcode + IEEE-754 `f32` / `u32` RGBA word payloads
- 8 compact opcodes: `Clear`, `FillRect`, `FillRoundedRect`, `FillCircle`, `StrokeLine`, `StrokePolyline`, `ClipRect`, `RestoreClip`
- Published via `ResourceStore` (`resource_payload`) with kind `nve.res.draw_list` and validated against expected kind on every host. See the [Vector Canvas (`DrawList`) Guide](/guides/canvas-draw1).

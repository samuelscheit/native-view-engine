# CommandBuffer & EventRing

Every UI mutation in Native View Engine travels across the Rust-to-host boundary inside a single contiguous, little-endian binary **`CommandBuffer`** (`NVE1`), and native host inputs return in a single batched **`EventRing`** (or zero-copy `NveEventBatch`). No per-property FFI calls, no `folly::dynamic`, and no JSON parsing ever touch the render loop.

## `NVE1` CommandBuffer Binary Layout

Defined in `crates/nve-abi/src/codec/` (`NVE_ABI_MAGIC = *b"NVE1"`, `NVE_ABI_VERSION = 1`, `HEADER_SIZE = 24`):

| Byte Offset | Size | Field | Type / Value |
| :--- | :--- | :--- | :--- |
| `0..4` | 4 B | `magic` | `0x3145564E` (`b"NVE1"` little-endian) |
| `4..6` | 2 B | `version` | `u16 = 1` |
| `6..8` | 2 B | `flags` | `u16` (reserved, `0`) |
| `8..12` | 4 B | `surface_id` | `u32` (`SurfaceId`) |
| `12..20` | 8 B | `frame_id` | `u64` (`FrameId`) |
| `20..24` | 4 B | `op_count` | `u32` (exact number of encoded ops following header) |
| `24..` | var | `commands` | Tightly packed TLV command records |

### Opcodes (`Opcode` `u8`)

Every command starts with a 1-byte `Opcode` discriminant followed by fixed-width little-endian fields:

| Value | Opcode | Payload Summary |
| :--- | :--- | :--- |
| `1` | `CreateNode` | `node_id: u32`, `kind: ComponentKind (u16)`, optional custom tag UTF-8 string |
| `2` | `RemoveNode` | `node_id: u32` |
| `3` | `SetChildren` | `parent: u32`, `count: u32`, `[child_id: u32; count]` |
| `4` | `SetText` | `node_id: u32`, `len: u32`, UTF-8 bytes |
| `5` | `SetLayout` | `node_id: u32` + fixed `LayoutProps` (6 `Dimension`s, flex enums, grow/shrink/gap, padding/margin `EdgeInsets`) |
| `6` | `SetStyle` | `node_id: u32` + fixed `StyleProps` (`background`, `text_color`, `border_color`, `border_width`, `border_radius`, `opacity`, `font_size`, `z_index`) |
| `7` | `SetRawProp` | `node_id: u32`, `key` string, tagged `RawPropValue` (`Null`, `Bool`, `I64`, `F64`, `String`, `Bytes`) |
| `8` | `SetEventMask` | `node_id: u32`, `mask: u64` (`EventMask` bitflags) |
| `9` | `DispatchCommand` | `node_id: u32`, `command_name` string, `arg_count` + `RawPropValue` args |
| `10` | `Commit` | `frame_id: u64` (atomic frame commit barrier) |

### Typed `ComponentKind` (`u16`)

`CreateNode` identifies built-in cross-platform primitives with a 2-byte enum so backends never hash tag strings:

- `0` = `Root`
- `1` = `View`
- `2` = `Text`
- `3` = `ScrollView`
- `4` = `Image`
- `5` = `TextInput`
- `6` = `Pressable`
- `7` = `SkiaCanvas`
- `0xFFFF` = `Custom` (carries a custom component name, e.g. imported React Native Fabric components)

### Zero-Allocation Streaming Decode (`CommandRef<'a>`)

`CommandBufferBuilder` packs fixed structs directly onto the stack before writing into the output `Vec<u8>`. On the receiver side, `CommandDecoder::iter_refs()` yields zero-copy `CommandRef<'a>` views — borrowing `&'a str`, `&'a [u8]`, and `ChildIdIter<'a>` straight out of the incoming byte slice without heap allocations.

```rust title="Encoding and zero-copy streaming decode" highlight="4-12,15-21"
use nve_abi::{
    ColorRgba, CommandBufferBuilder, CommandDecoder, CommandRef,
    ComponentKind, Dimension, LayoutProps, StyleProps,
};

let mut builder = CommandBufferBuilder::new(1, 1);
builder.create_node(1, ComponentKind::Root, None);
builder.create_node(2, ComponentKind::Text, None);
builder.set_text(2, "Zero-copy NVE1");
builder.set_layout(2, &LayoutProps {
    width: Dimension::Points(240.0),
    height: Dimension::Points(32.0),
    ..LayoutProps::default()
});
builder.set_style(2, &StyleProps {
    text_color: ColorRgba::WHITE,
    font_size: 18.0,
    ..StyleProps::default()
});
builder.set_children(1, &[2]);
builder.commit();
let bytes = builder.finish();

let mut decoder = CommandDecoder::new(&bytes)?;
for cmd in decoder.iter_refs() {
    if let CommandRef::SetText { node_id, text } = cmd? {
        assert_eq!((node_id, text), (2, "Zero-copy NVE1"));
    }
}
```

On Apple Silicon (`benchmarks/baseline.json`), encoding 1,000 nodes takes **21.17 µs** and streaming `CommandRef` decoding takes **18.05 µs** (~4.7 GiB/s).

<Callout kind="warning" title="Yoga scalar sanitization invariant">
In C++, `cxx/nve-fabric-bridge/src/command_decoder.hpp` validates every `f32` layout scalar (`is_valid_scalar`) to reject `NaN`, `Inf`, and magnitudes `|v| > 1e7f` before calling Yoga setters, preventing signed integer overflow UB inside Yoga's `StyleValuePool`.
</Callout>

## `EventRing` Binary Batching

Host input events (`NativeEvent`) flow back into Rust in one length-prefixed binary buffer via `encode_events` / `decode_events` (`crates/nve-abi/src/events.rs`), or zero-copy in-process via `NveSurfaceApi::dispatch_events_direct(handle, NveEventBatch)`.

### Subscription Bitmask (`EventMask`) & Event Kinds (`NativeEventKind`)

| Bit / Enum | Name | Payload Variant | Wire Tag |
| :--- | :--- | :--- | :--- |
| `1 << 0` / `1` | `Press` | `EventPayload::Point { x, y }` | `1` |
| `1 << 1` / `2` | `LongPress` | `EventPayload::Point { x, y }` | `1` |
| `1 << 2` / `3` | `Scroll` | `EventPayload::Scroll { x, y, content_width, content_height }` | `2` |
| `1 << 3` / `4` | `TextChange` | `EventPayload::Text(String)` | `3` |
| `1 << 4` / `5` | `Focus` | `EventPayload::Empty` | `0` |
| `1 << 5` / `6` | `Blur` | `EventPayload::Empty` | `0` |
| `1 << 6` / `7` | `Layout` | `EventPayload::Layout { x, y, width, height }` | `4` |
| `1 << 7` / `8` | `Custom` | `EventPayload::Custom { name, data }` | `5` |

Encoding 16 events takes **137.1 ns**; decoding 16 events takes **346.7 ns**.

## Compact Zero-JSON Keydowns (`NK1`)

Keyboard shortcuts and key events travel inside `NativeEventKind::Custom` (`name = "keydown"`) using the 4-byte-header **`NK1`** binary format instead of JSON:

```text
Offset:  0    1    2    3          4..N
Bytes:  'N'  'K'  '1'  flags_u8   utf8_key_bytes
```

Modifier bits packed into `flags_u8`:

- `0x01` (`KEYDOWN_FLAG_META`) — Command / Meta / Super
- `0x02` (`KEYDOWN_FLAG_CTRL`) — Control
- `0x04` (`KEYDOWN_FLAG_SHIFT`) — Shift
- `0x08` (`KEYDOWN_FLAG_ALT`) — Alt / Option

```rust title="Encode and decode NK1 keydown events"
use nve_abi::{decode_keydown_bytes, encode_keydown_bytes};

let wire = encode_keydown_bytes("k", true, false, false, false);
assert_eq!(&wire[..4], &[b'N', b'K', b'1', 0x01]);

let ev = decode_keydown_bytes(&wire).expect("valid NK1 keydown");
assert!(ev.meta && ev.key == "k");
```

`decode_keydown_bytes` also accepts compact UTF-8 shorthand strings such as `"Cmd+k"`, `"Ctrl+Shift+Enter"`, or `"Cmd++"` for CLI/test ergonomics without ever touching a JSON parser.

# `NodeStore`, `NVE2` Frames & `EventRing`

In-process UI mutations in Native View Engine write directly into a single-owner **`NodeStore`** via zero-alloc `Transaction` / `RowPatch` word tables — zero mirror trees and zero in-process serialization. Across C ABI (`cdylib`), network pairing (`nve-wire`), and Frame-0 persistence (`frame0.nve2`), deltas and keyframes travel in the compact **`NVE2`** v2 binary wire format, while native host inputs return in uniform, pointer-free 64-byte **`NveEvent`** records packed in **`NVEV`** v2 `EventRing` batches. No per-property FFI calls, no `folly::dynamic`, and no JSON parsing ever touch the render loop.

## `NVE2` v2 Wire Frame Layout

Defined in `packages/core/store/src/wire/` (`NVE2` v2):

- **Header**: `magic = b"NVE2"`, `version: u16 = 2`, `flags: u16`, `surface_id: u32`, `frame_id: u64`, `schema_hash: u64` (`XXH64`), followed by compact little-endian table-delta and structural opcodes.
- **Bit-packed word tables (`#[derive(NveTable)]`)**: Every UI domain (`Layout`, `Visual`, `Typography`, `TextContent`, `Interaction`, `Scroll`, `TextInput`, `Image`, `Accessibility`, `Transform2D`, plus opt-in module tables such as `nve.canvas`, `nve.svg`, `nve.blur`, `nve.motion`) packs into dense `u32` word rows with compile-time first-fit bit packing and per-table `EventSet<E>` subscriptions.
- **Flat resources (`FlatResource` / `ResourceStore`)**: Variable-length structured payloads (`ImageSrc`, `DrawList`, `BoxShadows`, `BackgroundFill`, `SvgPicture`, `AriaRelations`) live in flat 4-byte-aligned arenas indexed by generational `ResourceId` (`24-bit slot | 8-bit gen`).

```rust title="Direct Transaction write + NVE2 v2 wire encode/decode" highlight="4-14,17-19"
use nve_store::{ChangeSet, NodeId, NodeStore};
use nve_store::wire::{WireDecoder, WireEncoder};
use nve_tables::tables::{Layout, TextContent, Typography};

let mut store = NodeStore::new();
let mut tx = store.tx();
let label = tx.create();
tx.edit::<Layout>(label).width(240.0).height(32.0);
tx.edit::<Typography>(label).font_size(18.0);
tx.edit::<TextContent>(label).text("Zero-copy NVE2");
tx.set_children(NodeId::ROOT, &[label]);
let mut changes = ChangeSet::default();
tx.commit_into(&mut changes);

let wire = WireEncoder::encode_full(&store);
let mut replica = NodeStore::new();
WireDecoder::apply(&wire, &mut replica)?;
```

<Callout kind="warning" title="Yoga scalar sanitization invariant">
The Yoga layout engine (`packages/modules/layout-yoga`) maps non-finite layout results to `0.0f` (`sanitize_finite` in `yoga_shim.cpp`) and only forwards finite, non-negative sizes into Yoga setters. Huge style scalars (`|v| >= 2^31`) can still trigger float-cast-overflow UB inside Yoga's `StyleValuePool` until the upstream fix ships; see [Upstream Notes](/reference/upstream-notes).
</Callout>

## Uniform 64-Byte `NveEvent` & `NVEV` v2 `EventRing`

Every host input event (`NveEvent`, `#[repr(C)]`, locked at exactly **64 bytes** with zero embedded pointers) carries its target `NodeId`, `NveEventKind`, `TimestampUs`, packed scalar fields (`a..d`, `modifiers`, `flags`, `key_code`), and slice offsets (`text_off`/`text_len`, `name_off`/`name_len`) into one shared UTF-8/byte blob inside `NveEventBatch` (`NVEV` v2 `EventRing`).

### Per-Table Event Subscriptions (`EventSet<E>`) & `NveEventKind`

| Table / Domain | Event Kinds | Payload Fields |
| :--- | :--- | :--- |
| `Interaction` | `Press`, `LongPress`, `PointerDown`, `PointerMove`, `PointerUp`, `PointerCancel`, `PointerEnter`, `PointerLeave`, `Wheel`, `KeyDown`, `KeyUp`, `Focus`, `Blur` | Local/viewport coordinates, pointer ID/buttons, wheel deltas, W3C key + physical code + modifiers |
| `Scroll` | `Scroll` | `x`, `y`, `content_width`, `content_height` |
| `TextInput` | `TextChange`, `Submit`, `CompositionStart`, `CompositionUpdate`, `CompositionEnd`, `SelectionChange` | UTF-8 text span in shared `EventRing` blob + selection/composition offsets |
| `Layout` / `Custom` | `Layout`, `Custom` | `x`, `y`, `width`, `height` or custom event name + binary payload slice |

Because `NveEvent` is pointer-free and exactly 64 bytes on both 32-bit and 64-bit targets, C++, Swift, Java/JNI, Dart, TypeScript, and Rust all read and write the exact same `EventRing` layout (`ValidatedEvents` validates all offsets and UTF-8 once at ingress).

Modifier bits in `modifiers: u8`:

- `0x01` (`NVE_KEY_MOD_META`) — Command / Meta / Super
- `0x02` (`NVE_KEY_MOD_CTRL`) — Control
- `0x04` (`NVE_KEY_MOD_SHIFT`) — Shift
- `0x08` (`NVE_KEY_MOD_ALT`) — Alt / Option
- `0x10` (`NVE_KEY_MOD_REPEAT`) — Auto-repeat keydown

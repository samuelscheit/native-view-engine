# Vector Canvas (`DrawList` / `nve.res.draw_list`)

For telemetry sparklines, charts, custom gauges, and bespoke vector chrome that should render at native refresh rate on **every** host — even hosts without Skia linked — `nve-canvas` (`packages/modules/canvas`) provides **`DrawList`**: a canonical 4-byte-aligned `FlatResource` (`nve.res.draw_list`) referenced by the `nve.canvas` table (`draw_list: Res<DrawList>`).

## Wire Layout

Defined in `packages/modules/canvas/src/flat.rs` (`u32`-word stream, 4-byte aligned, little-endian):

| Word Offset | Size | Field | Value / Bounds |
| :--- | :--- | :--- | :--- |
| `0` | 4 B | `op_count` | `u32` (strictly capped at `MAX_DRAW_OPS = 65_536`) |
| `1..` | var | `ops` | Stream of `u32` opcode words + IEEE-754 `f32` / `u32` RGBA word payloads |

### Supported Operations (`CanvasOp`)

| Opcode (`u32`) | Variant | Word Payload |
| :--- | :--- | :--- |
| `1` | `Clear` | `color: ColorRgba` (`u32`) |
| `2` | `FillRect` | `x, y, w, h: f32`, `color: ColorRgba` |
| `3` | `FillRoundedRect` | `x, y, w, h, radius: f32`, `color: ColorRgba` |
| `4` | `FillCircle` | `cx, cy, radius: f32`, `color: ColorRgba` |
| `5` | `StrokeLine` | `x0, y0, x1, y1, width: f32`, `color: ColorRgba` |
| `6` | `StrokePolyline` | `width: f32`, `color: ColorRgba`, `point_count: u32` (max `16_384`), `[(x, y): (f32, f32)]` |
| `7` | `ClipRect` | `x, y, w, h: f32` |
| `8` | `RestoreClip` | *(empty — pops previous clip state; nested clips capped at depth `64`)* |

`<DrawList as FlatResource>::validate` / `DrawListView` and every generated host decoder validate finite coordinates, non-negative stroke widths and radii, clip-stack balance (capped at `MAX_CLIP_DEPTH = 64`), polyline point caps, resource kind (`nve.res.draw_list`), and exact byte length before a single draw call hits the GPU or OS graphics context.

## Building a `DrawList` in Rust

```rust title="Recording a telemetry sparkline into flat nve.res.draw_list" highlight="4-16"
use nve_abi::ColorRgba;
use nve_canvas::{DrawList, DrawListRecorder};

pub fn record_sparkline(samples: &[f32]) -> DrawList {
    let mut rec = DrawListRecorder::new();
    rec.fill_rounded_rect(0.0, 0.0, 280.0, 64.0, 10.0, ColorRgba::rgb(15, 23, 42));
    rec.clip_rect(8.0, 8.0, 264.0, 48.0);
    let pts: Vec<(f32, f32)> = samples
        .iter()
        .enumerate()
        .map(|(i, &v)| (8.0 + i as f32 * 12.0, 56.0 - v.clamp(0.0, 48.0)))
        .collect();
    rec.stroke_polyline(&pts, 2.0, ColorRgba::rgb(56, 189, 248));
    rec.restore_clip();
    rec.finish()
}
```

## Native Host Renderer Mapping

Every platform host decodes the exact same `nve.res.draw_list` word stream via Rust `DrawListView` or decoders generated from `DRAW_LIST_CODEC_DESC` (`nve-cli codegen abi`) for C++ (`packages/modules/canvas/cxx/include/nve/canvas/draw_list.hpp`), JVM (`dev.nve.host.DrawList`), Swift (`NveHost.NveDrawList`), Dart (`package:nve_host/nve_draw_list.generated.dart`), and TypeScript (`@nve/host/draw-list`):

| Host Target | Native Graphics API | Implementation |
| :--- | :--- | :--- |
| **Desktop Skia** | Skia `Canvas` (Metal / Vulkan / D3D12) or software `PixelBuffer` | `packages/modules/canvas/skia` |
| **Web WASM** | HTML5 `<canvas>` 2D (`CanvasRenderingContext2D`) | `packages/modules/canvas/web` |
| **Windows** | Direct2D (`ID2D1RenderTarget` / `ID2D1PathGeometry`) | `hosts/windows-shell/NveWinD2DRenderer.cpp` |
| **Linux GTK4** | Cairo (`cairo_t` via `GtkDrawingArea` / `GtkSnapshot`) | `hosts/gtk-shell/NveGtkMedia.cpp` |
| **Qt 6** | `QPainter` (Widgets & Quick texture) | `hosts/qt-shell/NveQtDrawList.cpp` |
| **Android JNI** | `android.graphics.Canvas` (`NveCanvasView.java`) | `hosts/android-shell/android-app/src/dev/nve/android/NveCanvasView.java` |
| **Jetpack Compose** | Compose `Canvas` (`DrawScope`) | `hosts/compose-kit/src/main/kotlin/dev/nve/compose/NveDrawListPainter.kt` |
| **SwiftUI** | SwiftUI `Canvas` / CoreGraphics | `hosts/swiftui-kit/Sources/NveSwiftUI/NveDrawListRenderer.swift` |
| **Flutter** | Impeller / Skia `dart:ui.Canvas` (`NveCanvasTablePainter`) | `hosts/flutter-plugin/lib/src/draw_list_painter.dart` |

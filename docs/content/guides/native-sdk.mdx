# Host Capabilities (`nve-host-services` + `packages/modules/*`)

Native platform capabilities are decomposed into a tiny shared core (`packages/core/host-services`) plus standalone opt-in capability crates under `packages/modules/<name>/`. Apps depend only on the exact modules they use — zero umbrella bloat.

- **In-process Rust-to-Rust (`NativeHostServices`, `MemoryHostServices`, `SkiaHostServices`)**: Clients resolve each module's typed `*Backend` trait directly via `nve_host_services::resolve_typed` — **zero serialization, zero wire encoding, zero extra allocations**.
- **Cross-language FFI (`FfiHostServices` over `NVE_IFACE_HOST = 5`)**: When a Rust module runs inside a C++/Swift/Kotlin/Dart host, clients fall back seamlessly to the compact zero-JSON binary wire protocol over `NVE_IFACE_HOST = 5` and `NveChannelBus`.

## Composing Only What You Need

Every module's client borrows `&dyn HostServiceProvider` — backed by `FfiHostServices` in hosted `NveApp` modules, `NativeHostServices` on desktop, or `MemoryHostServices` in tests:

```rust title="Direct typed clients from standalone capability crates" highlight="1-5,8-18"
use nve_clipboard::ClipboardClient;
use nve_filesystem::{FileFilter, FilePickerOptions, FilesystemClient, StandardPathKind};
use nve_haptics::{HapticsClient, ImpactStyle};
use nve_host_services::{HostServiceProvider, ServiceError};
use nve_secure_store::SecureStoreClient;

pub fn export_workspace_token(host: &dyn HostServiceProvider) -> Result<(), ServiceError> {
    if let Some(secret) = SecureStoreClient::new(host).get_string("nve.studio", "sync_token")? {
        ClipboardClient::new(host).write_text(&secret)?;
        HapticsClient::new(host).impact(ImpactStyle::Medium)?;
    }

    let fs = FilesystemClient::new(host);
    let data_dir = fs.standard_path(StandardPathKind::AppData)?;
    let _picked = fs.pick_open_files(&FilePickerOptions {
        title: Some("Import Snapshot".into()),
        multiple: false,
        filters: vec![FileFilter::new("NVE Snapshot", &["nvesnap", "nvewal"])],
        ..Default::default()
    })?;
    println!("AppData: {data_dir}");
    Ok(())
}
```

## Live Theme (`NVT2`) & Locale (`NVL1`) on `NveChannelBus`

System appearance and locale snapshots bypass JSON completely and publish directly onto `NveChannelBus` (`CHANNEL_ID_THEME = 1`, `CHANNEL_ID_LOCALE = 2`) with `NVE_CHANNEL_FLAG_RETAIN` so late-mounting surfaces receive the latest state immediately.

### Fixed 16-Byte `NVT2` Theme Snapshot (`ThemeWireLayout`)

| Bytes | Field | Encoding |
| :--- | :--- | :--- |
| `0..4` | `magic` | `b"NVT2"` |
| `4` | `color_scheme` | `0 = Unspecified`, `1 = Light`, `2 = Dark` |
| `5` | `contrast` | `0 = Standard`, `1 = High` |
| `6` | `flags` | Bit 0: `reduced_motion`, Bit 1: `reduced_transparency` |
| `7` | `reserved` | `0` |
| `8..12` | `accent_rgba` | `u32` LE (`0xRRGGBBAA`, `0` if unset) |
| `12..14` | `font_scale_x1000` | `u16` LE (e.g. `1000` = `1.0x`, `1250` = `1.25x`) |
| `14..16` | `scale_factor_x100` | `u16` LE (e.g. `200` = `2.0x` Retina) |

`NVL1` encodes `LocaleSnapshot` (`b"NVL1"`, `version = 1`, BCP-47 language tag, region subtag, `TextDirection::Ltr | Rtl`, and 24-hour clock flag). `SystemEnvBridge` handles both initial pull (`get_theme`/`get_locale`) and live push updates (`EVENT_THEME_CHANGED = 1`, `EVENT_LOCALE_CHANGED = 2`).

## Zero-Mock Testing With `MemoryHostServices`

`MemoryHostServices` (`packages/core/host-services/src/registry.rs`) is an empty registry onto which tests register only the deterministic `Memory*` handlers they exercise (`MemoryClipboard`, `MemoryFilesystem`, `MemorySystemEnv`, `MemoryStorage`, etc.) — supporting fault injection and direct zero-serialization typed dispatch in sub-millisecond `cargo test` runs.

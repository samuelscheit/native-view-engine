# Local-First Storage & CRDTs

Native View Engine treats instant cold start and offline-first multi-device collaboration as first-class engine primitives — zero SQLite/JSON glue required for Frame-0 persistence or deterministic state convergence.

## Frame-0 `NVE2` Keyframe Boot (`Frame0File` / `frame0.nve2`)

`packages/core/engine/src/persistence/` persists Frame 0 as a single standard `NVE2` keyframe (`frame == 1`) followed by a 40-byte little-endian footer (`Frame0Footer`):

| Offset (from end) | Size | Field | Description |
| :--- | :--- | :--- | :--- |
| `-40..-36` | 4 B | `node_count` | Exact live `NodeStore` node count used to pre-size arenas in O(1) allocations |
| `-36..-32` | 4 B | `flags` | Format flags (`0`) |
| `-32..-24` | 8 B | `table_schema_hash` | Deterministic `XXH64` over `CORE_TABLE_DESCS` (`core_tables_schema_hash()`) |
| `-24..-16` | 8 B | `app_build_id` | Caller build/schema tag (`0` default for `nve prerender` & `nve-skia-shell`) |
| `-16..-8` | 8 B | `env_hash` | Optional environment/theme tag |
| `-8..0` | 8 B | `payload_xxh64` | `XXH64` over the entire `NVE2` payload + first 32 footer bytes |

Booting `frame0.nve2` decodes directly into a pre-sized `StoreWireReplica` and computes fresh live Taffy layout at the actual launch viewport and DPI — eliminating stale baked rects with zero `mmap` and zero `unsafe` (`< 2 ms` for 1,000 nested nodes).

## Crash-Atomic State Persistence (`StateFile` / `state.nve`)

Application state (`WorkspaceState` `NWS1`, `SignalArchive` `NVE_SIG1`, `FormDraftStore`) persists via `StateFile`, which wraps an arbitrary binary payload in a 24-byte `NVESTATE` header (`magic: 8B | schema_version: u32 | payload_len: u32 | xxh64: u64` covering header prefix + payload) and writes via exclusive `create_new` sibling temp file → `sync_all()` → atomic `rename()` → parent-directory `sync_all()`. Corrupt files are quarantined to `<file>.corrupt`; I/O and schema-version mismatches never delete user data.

## Zero-Dependency Binary CRDT Engine (`NveCrdtDelta`)

`packages/core/interop/src/crdt/` implements a complete suite of state- and delta-based CRDTs with zero external dependencies and compact binary delta sync (`NveCrdtDelta`):

| Primitive | Type | Semantics |
| :--- | :--- | :--- |
| **Hybrid Logical Clock** | `HlcClock`, `HlcTimestamp`, `OpId`, `VersionVector` | Causal wall-clock + logical counter + deterministic `PeerId` tie-breaking |
| **Last-Write-Wins Register** | `LwwRegister<T>` | Total-order conflict resolution by `HlcTimestamp` for scalar fields (titles, statuses, assignees) |
| **Counters** | `GCounter`, `PnCounter` | Per-peer monotonic increment/decrement vectors (reactions, unread counts, votes) |
| **Observed-Remove Set** | `OrSet<T>` | Add-wins sets supporting concurrent add + remove without resurrection bugs (tags, labels, members) |
| **Replicated Growable Array** | `RgaList<T>` | Ordered sequences with causal insertion and tombstoning (collaborative doc blocks, checklists, kanban order) |

### `NveCrdtDelta` Binary Delta Wire Layout

Defined in `packages/core/interop/src/crdt/wire.rs` (minimum 34 bytes, strict bounds `MAX_WIRE_BYTES = 16 MiB`, `MAX_RECORDS = 1_000_000`):

```text
magic("NVE_CRDT": 8B) | version(u16=2) | sender(u64)
  | vv_len(u32) + [peer: u64, seq: u64]*
  | record_count(u32) + [rec_len: u32, tag: u8, body]*
  | checksum(u64 XXH64 over all preceding bytes)
```

Supported record tags: `1 = LwwSet`, `2 = GCounterSet`, `3 = PnCounterSet`, `4 = OrSetAddU64`, `5 = OrSetRemove`, `6 = RgaInsert`, `7 = RgaDelete`, `8 = OrSetAddStr`.

```rust title="Creating a peer, mutating CRDTs, and encoding an NveCrdtDelta packet" highlight="4-12"
use nve_interop::crdt::{NveCrdtDelta, HlcClock, LwwRegister, OrSet, RgaList};

let mut clock = HlcClock::new(1 /* peer_id */);
let mut title = LwwRegister::new(String::new(), clock.tick(1_700_000_000_000));
title.set("Q4 Architecture Spec".into(), clock.tick(1_700_000_000_010));

let mut tags = OrSet::<String>::new();
let _add_delta = tags.insert("local-first".into(), clock.next_op_id(1_700_000_000_020));

let mut blocks = RgaList::<String>::new();
let _ins_delta = blocks.insert_after(None, "Intro paragraph".into(), clock.next_op_id(1_700_000_000_030));
```

In `examples/studio-workspace`, `StudioCrdtDoc` combines `LwwRegister`, `PnCounter`, `OrSet`, and `RgaList` with verified 5-peer partition-heal convergence and crash-atomic `StateFile` persistence.

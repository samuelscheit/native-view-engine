# Local-First Storage & CRDTs

Native View Engine treats instant cold start and offline-first multi-device collaboration as first-class engine primitives — zero SQLite/JSON glue required for Frame-0 persistence or deterministic state convergence.

## Instant-Boot `MmapSnapshot` (`NVE_SNAP`)

`packages/core/engine/src/snapshot/` freeze-dries both the last rendered binary `CommandBuffer` (**Frame 0**) and a pointer-free `RelocatableStateArena` into a single 8-byte-aligned memory-mapped file (`NVE_SNAP`, 80-byte fixed header):

| Offset | Size | Field | Description |
| :--- | :--- | :--- | :--- |
| `0..8` | 8 B | `magic` | `b"NVE_SNAP"` |
| `8..16` | 8 B | `format_version`, `app_schema_version` | `u32 = 1`, caller schema version |
| `16..24` | 8 B | `flags`, `reserved` | `u32`, `u32 (0)` |
| `24..32` | 8 B | `checksum_fnv64` | FNV-1a 64-bit over `0..24` + `32..file_len` |
| `32..48` | 16 B | `frame0_offset`, `frame0_len` | 8-byte aligned Frame-0 `NVE1` `CommandBuffer` |
| `48..64` | 16 B | `state_offset`, `state_len` | 8-byte aligned `RelocatableStateArena` / `NVE_SIG1` bytes |
| `64..80` | 16 B | `meta_offset`, `meta_len` | Optional viewport / metadata bytes |

Because `MmapSnapshot` contains zero absolute memory pointers, it survives ASLR, crashes, OS reboots, and app upgrades. Measured cold boot on Apple Silicon: **`29 µs`** raw `mmap` open and **`82–136 µs`** full Frame-0 + 100-row state restore.

## Crash-Safe Write-Ahead Log (`.nvewal` / `NVE_WAL1`)

Writing a full snapshot on every keystroke is wasteful. `packages/core/engine/src/snapshot_wal/` pairs `MmapSnapshot` with an append-only binary WAL (`NVE_WAL1`, 24-byte header bound to `base_snapshot_checksum`):

- **Record framing:** `seq: u64` (monotonic from `1`) | `kind: u8` (`1 = StateDelta`, `2 = Frame0Delta`, `3 = Checkpoint`) | `payload_len: u32` | `payload_bytes` | `checksum_fnv64: u64`.
- **Torn-tail recovery vs. corruption rejection:** On `SnapshotWal::open_or_create`, any torn *trailing* record at EOF (mid-write power loss) is cleanly truncated back to the last valid boundary, whereas any corrupted *middle* record returns a strict `WalError`.
- **Atomic compaction:** `SnapshotWal::compact_into_snapshot` writes a new `NVE_SNAP` via sibling temp file + `sync_all()` + atomic `rename()`, then rotates the `.nvewal` file to a clean 24-byte header bound to the new checksum.

## Zero-Dependency Binary CRDT Engine (`NVC1`)

`packages/core/interop/src/crdt/` implements a complete suite of state- and delta-based CRDTs with zero external dependencies and compact binary delta sync (`NVC1`):

| Primitive | Type | Semantics |
| :--- | :--- | :--- |
| **Hybrid Logical Clock** | `HlcClock`, `HlcTimestamp`, `OpId`, `VersionVector` | Causal wall-clock + logical counter + deterministic `PeerId` tie-breaking |
| **Last-Write-Wins Register** | `LwwRegister<T>` | Total-order conflict resolution by `HlcTimestamp` for scalar fields (titles, statuses, assignees) |
| **Counters** | `GCounter`, `PnCounter` | Per-peer monotonic increment/decrement vectors (reactions, unread counts, votes) |
| **Observed-Remove Set** | `OrSet<T>` | Add-wins sets supporting concurrent add + remove without resurrection bugs (tags, labels, members) |
| **Replicated Growable Array** | `RgaList<T>` | Ordered sequences with causal insertion and tombstoning (collaborative doc blocks, checklists, kanban order) |

### `NVC1` Binary Delta Wire Layout

Defined in `packages/core/interop/src/crdt/wire.rs` (minimum 30 bytes, strict bounds `MAX_WIRE_BYTES = 16 MiB`, `MAX_RECORDS = 1_000_000`):

```text
magic("NVC1": 4B) | version(u16=1) | sender(u64)
  | vv_len(u32) + [peer: u64, seq: u64]*
  | record_count(u32) + [rec_len: u32, tag: u8, body]*
  | checksum(u64 FNV-1a64 over all preceding bytes)
```

Supported record tags: `1 = LwwSet`, `2 = GCounterSet`, `3 = PnCounterSet`, `4 = OrSetAddU64`, `5 = OrSetRemove`, `6 = RgaInsert`, `7 = RgaDelete`, `8 = OrSetAddStr`.

```rust title="Creating a peer, mutating CRDTs, and encoding an NVC1 delta packet" highlight="4-12"
use nve_interop::crdt::{CrdtDeltaPacket, HlcClock, LwwRegister, OrSet, RgaList};

let mut clock = HlcClock::new(1 /* peer_id */);
let mut title = LwwRegister::new(String::new(), clock.tick(1_700_000_000_000));
title.set("Q4 Architecture Spec".into(), clock.tick(1_700_000_000_010));

let mut tags = OrSet::<String>::new();
let _add_delta = tags.insert("local-first".into(), clock.next_op_id(1_700_000_000_020));

let mut blocks = RgaList::<String>::new();
let _ins_delta = blocks.insert_after(None, "Intro paragraph".into(), clock.next_op_id(1_700_000_000_030));
```

# Universal Interop & Islands (`nve-interop`)

`packages/core/interop` coordinates hybrid applications in both directions: embedding NVE surfaces inside React Native, Flutter, SwiftUI, Jetpack Compose, or Web apps, **and** hosting opt-in foreign framework `<Island>` surfaces inside an NVE view tree — all unified behind `InteropRuntime`.

## `InteropRuntime` Subsystems

```rust title="packages/core/interop/src/lib.rs"
pub struct InteropRuntime {
    pub surfaces: SurfaceOrchestrator,
    pub layout: LayoutNegotiator,
    pub gestures: GestureArbitrator,
    pub channels: NveChannelBus,
    pub windows: WindowManager,
}
```

### 1. `SurfaceOrchestrator`

Tracks the full parent/child tree of nested surfaces across heterogeneous `FrameworkKind`s (NVE, React Native, Flutter, SwiftUI, Compose, Web), manages `LifecycleState` transitions, propagates `SurfaceEnvironment` (`ColorScheme`, `ThemeContext`, `SafeAreaInsets`, `scale_factor`) with subtree `EnvironmentOverrides`, and performs atomic bottom-up cascading teardown (`destroy_surface_cascade`) so gesture locks, cached layouts, and channel subscriptions never leak.

### 2. `LayoutNegotiator`

Negotiates intrinsic sizing (`SizeConstraints` → `LayoutResult` + `BaselineMetrics`) across framework boundaries using `MeasurableSurface` and DPR pixel snapping (`LayoutProposal`).

- **Cached hit:** **30.13 ns** (`rust::interop/intrinsic_layout/cached_hit`)
- **Uncached measure & snap:** **72.69 ns** (`rust::interop/intrinsic_layout/uncached_measure_and_snap`)

### 3. `GestureArbitrator`

Resolves nested scroll and pointer ownership across mixed-framework ancestor chains (`SurfaceOrchestrator::ancestor_chain`) with zero heap allocations using inline `SurfaceChain` and `FastU32Map`:

- Tracks `GestureCapabilities`, `ScrollAxes`, and `ScrollEdgeState` (so an inner Flutter or RN list at its top/bottom scroll boundary cleanly hands off overscroll to an outer NVE `ScrollView`).
- Evaluates `PointerSample` (`PointerPhase`) into `ArbitrationDecision` (`GestureDisposition::Claim | PassThrough | DeferToParent` + `ArbitrationReason`).
- **Measured nested scroll sequence:** **64.51 ns** (`rust::interop/gesture_arbitration/nested_scroll_sequence`).

### 4. `NveChannelBus`

Binary pub/sub and retained shared-state bus connecting Rust surfaces and native hosts (`ChannelId`, `ChannelMessage`, `ChannelPayload`, `PayloadEncoding::{Binary, Text}`). Built-in retained channels:

| `ChannelId` | Constant | Topic | Wire Format |
| :--- | :--- | :--- | :--- |
| `1` | `CHANNEL_ID_THEME` | `"theme"` | `ThemeSnapshot` / binary |
| `2` | `CHANNEL_ID_LOCALE` | `"locale"` | Binary |
| `3` | `CHANNEL_ID_AUTH` | `"auth"` | Binary / `NveBinValue` |
| `4` | `CHANNEL_ID_NAVIGATION` | `"navigation"` | `NVN1` |

- **Publish to 1 subscriber:** **47.49 ns**
- **Publish to 8 subscribers:** **66.69 ns**
- **Publish to 64 subscribers:** **385.82 ns**

## Foreign Framework `<Island>` Runtime (Backlog)

Opt-in foreign-framework `<Island>` mounting (React Native, Flutter `FlutterEngineGroup`, SwiftUI, and Jetpack Compose view/GPU-texture handoff) is tracked as an open backlog item in `docs/BACKLOG.md` until real cross-runtime compositor bridges are implemented and verified end-to-end.

## Panic-Isolated Plugin Host (`NvePluginHost`)

`packages/core/interop/src/plugin_host/` lets flagship applications like NVE Studio dynamically load third-party native-speed Rust plugins via `nve_get_interface` (`PluginMetadata`, `PluginCapabilities`, `PluginRequirement`), allocating isolated generational `SurfaceId`s directly from the shared `SurfaceOrchestrator`:

- Plugins render into isolated `NvePluginSlot`s with dedicated `SurfaceId`s.
- Because `export_nve_app!` wraps every FFI call in `ffi_catch_unwind`, a bug inside a third-party plugin faults only its slot rather than crashing the host application.

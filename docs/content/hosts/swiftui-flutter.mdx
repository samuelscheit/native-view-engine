# SwiftUI & Flutter Host Kits (`hosts/swiftui-kit`, `hosts/flutter-plugin`)

When you want to embed NVE Rust components natively inside existing **SwiftUI** or **Flutter** apps — or build a full Flutter/SwiftUI shell over an NVE core — `NveSwiftUI` and `nve_flutter` bind straight to `nve_get_interface(1..=5)` over direct typed binary FFI.

## SwiftUI Host Kit (`hosts/swiftui-kit`)

`NveSwiftUI` is a Swift Package Manager library supporting **iOS 16+** (`UIViewRepresentable`) and **macOS 13+** (`NSViewRepresentable`), importing the generated C ABI header (`nve_abi.generated.h`) through the `CNveAbi` target of `packages/core/host-swift`:

- **`NveDirectArena` & `NveDirectEncodable`** — Strongly typed Swift prop structs (including those emitted by `cargo nve codegen hybrid --target swift`) conform to `NveDirectEncodable` and encode directly into a stack-backed `NveDirectArena` using compile-time `StaticString` keys for `NveComponentApi::set_props_direct` — zero `[String: Any]` boxing and zero heap buffer pinning.
- **`NveSurfaceRepresentable` & `NveSceneCanvasView`** — Integrates `sizeThatFits` intrinsic layout negotiation (`NveLayoutApi::measure`), CoreGraphics/SwiftUI Canvas `NVE_DRAW1` vector rendering, reactive direct prop updates, and automatic `dismantleUIView` / `dismantleNSView` teardown.
- **`NveSurfaceController`, `NveEventRingCodec`, `NveChannelClient`** — Bind `NveSurfaceApi`, binary `EventRing` encoding, and thread-safe `NveChannelBus` streams.

```swift title="Zero-copy typed SwiftUI embedding with NveDirectEncodable" highlight="1-6,15-21"
struct CounterProps: Equatable, NveDirectEncodable {
    let title: String
    let count: Int64
    func encodeDirect(into writer: inout NveDirectMapWriter) {
        writer.put("title", title)
        writer.put("count", count)
    }
}

struct CounterHostView: View {
    @StateObject private var controller = NveSurfaceController(
        vtableSymbol: "nve_get_interface",
        backend: .fabric
    )
    @State private var count: Int64 = 0

    var body: some View {
        NveSurfaceRepresentable(
            componentName: "NveCounterCard",
            props: CounterProps(title: "SwiftUI + NVE", count: count),
            controller: controller,
            onEvent: { event in if event.name == "onIncrement" { count += 1 } }
        )
    }
}
```

```bash title="Run SwiftUI host kit tests"
swift test --package-path hosts/swiftui-kit
```

## Flutter Plugin (`hosts/flutter-plugin`)

`nve_flutter` is a thin Flutter host on top of `package:nve_host` (`packages/core/host-dart`): one `libnve_runtime` surface per `NveCanvasController`, driven over `dart:ffi` (`RuntimeSession`). The runtime owns the app (`nve_get_interface`), layout, hit-testing, scrolling, and live pairing; the plugin only renders the published scene and forwards input.

- **`NveCanvasView` — zero `PlatformView`s**: a `RenderBox` that lays the surface out at its own size, paints the published scene tables (`Visual`, `Transform`, inherited `Typography`, `TextContent`, `TextInput`, `Image`, scroll shifts, z-order, clipping) with Flutter's `TextPainter` onto Impeller/Skia, maps pointers to runtime `Pointer*`/`Press` events and wheel/drag to `scroll_by`, and exposes `SemanticsNode`s from the `Accessibility` table.
- **Module tables** paint through `NveTablePainter`s; the canvas module's `NVE_DRAW1` draw lists ship built in.
- **`NvePairedSurface`** pairs with `nve dev` (`nve://pair?…`) through the runtime's built-in pair client.
- **Generated widgets** (`nve codegen export --target flutter`) attach the component library to a runtime surface; commands travel as root `Custom` events.

```dart title="Running an NVE app on Flutter's Canvas" highlight="6-9,20"
class CounterScreen extends StatefulWidget {
  const CounterScreen({super.key, required this.appLibrary});
  final String appLibrary;
  @override
  State<CounterScreen> createState() => _CounterScreenState();
}

class _CounterScreenState extends State<CounterScreen> {
  late final NveCanvasController _controller = NveCanvasController.open(
    app: ffi.DynamicLibrary.open(widget.appLibrary),
  );

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) => Scaffold(body: NveCanvasView(controller: _controller));
}
```

```bash title="Run Flutter plugin tests (live runtime + kitchen sink)"
(cd hosts/flutter-plugin && flutter analyze && flutter test)
```

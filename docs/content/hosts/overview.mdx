# Platform Hosts Overview

Every platform host in `native-view-engine` consumes the exact same `NVE1` binary `CommandBuffer` and `nve_get_interface(1..=5)` C ABI. C++ and Objective-C++ shells share `cxx/nve-fabric-bridge/include/nve_host_runtime.hpp` (`nve::NativeHostSession` + `nve::RetainedViewReconciler`), while Apple hosts share `hosts/apple-common/` so zero layout, hot-swap, or image-cache logic is duplicated.

## All 10 Host Targets at a Glance

| Host Target | Directory | Rendering / UI Layer | Text Shaping | Accessibility & IME | Multi-Window | Live Pairing (`--pair-connect`) |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Desktop Skia** | `crates/nve-backend-skia`, `hosts/skia-shell` | Skia Metal / Vulkan / D3D12 / CPU + `softbuffer` (`winit`) | `cosmic-text 0.19` | `TextInput` IME + selection + OS clipboard | Yes (`winit`) | Yes (UDP / TCP / WS) |
| **Web WASM & SSR** | `crates/nve-backend-web`, `hosts/web-shell` | Browser DOM + Option 5 CSS cache + `<canvas>` | Browser native | Full ARIA + native DOM IME + HTML5 SSR | Yes (`ACTIVE_SHELLS` + `BroadcastChannel`) | Yes (`?pair=ws://...`) |
| **macOS AppKit** | `hosts/macos-shell`, `hosts/apple-common` | `NSView` / `NSTextField` / `NSScrollView` / `CGContext` (+ RN-macOS Fabric) | CoreText / AppKit | VoiceOver + macOS IME | Yes (`NveMacWindowManager`) | Yes (`nve::PairClient`) |
| **iOS / iPadOS UIKit** | `hosts/ios-shell`, `hosts/apple-common` | `UIView` / `UILabel` / `UIScrollView` / `CGContext` (+ RN Fabric) | CoreText / UIKit | VoiceOver + iOS IME | Yes (`UIWindowScene` / iOS 27) | Yes (`nve::PairClient`) |
| **Windows 11 / RNW** | `hosts/windows-shell` | Win32 Direct2D / WIC + RNW 0.88 Composition Fabric | DirectWrite (`IDWriteTextLayout`) | UI Automation + Win32 IME | Yes (`NveWinWindowManager`) | Yes (WinSock2 `PairClient`) |
| **Android JNI** | `hosts/android-shell` | `DirectByteBuffer` slabs + `NveCanvasView` + RN Android Fabric | Android `StaticLayout` / `Paint` | TalkBack (`NVE_MET1`) + Android IME | Single/Activity | Yes (`NveAndroidPairJni`) |
| **Jetpack Compose** | `hosts/compose-kit` | `NveSceneBuffer` + `NveSceneCanvas` + `@Composable NveSurface` | Compose / Android text | `Modifier.semantics` (`NVE_MET1`) | Activity / Dialog | Via `NveBridgeBackend` |
| **Qt 6 (Widgets + Quick)** | `hosts/qt-shell` | `NveQtQuickItem` GPU RHI `QSGNode` + `NveQtWidget` | `QTextLayout` / `QFontMetricsF` | Qt Accessibility + Qt IME | Yes (`NveQtWindowManager`) | Yes (`nve::PairClient`) |
| **Linux GTK4** | `hosts/gtk-shell` | `GtkFixed` / `GtkLabel` / `GtkScrolledWindow` / `GtkEntry` / Cairo | Pango (`PangoLayout`) | AT-SPI + GTK4 IME | Yes (`NveGtkWindowManager`) | Yes (`nve::PairClient`) |
| **SwiftUI & Flutter** | `hosts/swiftui-kit`, `hosts/flutter-plugin` | `NveSurfaceRepresentable` / `NveSceneCanvasView` & `NveCanvasView` (Impeller) | CoreText / Flutter `TextPainter` | SwiftUI / Flutter Semantics | Host-managed | Roadmap (thin-client UI) |

## Shared Runtime Architecture

```text
                ┌──────────────────────────────────────────┐
                │    Compiled Rust App (nve_get_interface) │
                └────────────────────┬─────────────────────┘
         ┌───────────────────────────┼───────────────────────────┐
         ▼                           ▼                           ▼
  Pure-Rust Hosts          Shared C++20 Bridge           Direct FFI Host Kits
  ├─ hosts/skia-shell      cxx/nve-fabric-bridge         ├─ hosts/swiftui-kit (CNveAbi)
  ├─ hosts/web-shell       ├─ hosts/apple-common         ├─ hosts/flutter-plugin (dart:ffi)
  └─ nve-backend-headless  │   ├─ hosts/macos-shell      └─ hosts/compose-kit (JNI slabs)
                           │   └─ hosts/ios-shell
                           ├─ hosts/windows-shell
                           ├─ hosts/qt-shell
                           ├─ hosts/gtk-shell
                           └─ hosts/android-shell
```

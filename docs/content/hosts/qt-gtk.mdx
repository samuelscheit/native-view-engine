# Qt 6 & GTK4 Desktop Shells (`hosts/qt-shell`, `hosts/gtk-shell`)

Both desktop Linux / cross-platform C++ shells build directly on `cxx/nve-fabric-bridge/include/nve_host_runtime.hpp` (`nve::NativeHostSession` + `nve::RetainedViewReconciler`), sharing layout, hot-swap, `NVE_DRAW1`, `MmapSnapshot` Frame-0 boot, and `nve::PairClient` live pairing.

## Qt 6 Shell (`hosts/qt-shell`)

`hosts/qt-shell` ships **two** native Qt 6 adapters from one codebase:

### 1. GPU Qt Quick Scene Graph (`NveQtQuickItem`)

Enabled automatically whenever `Qt6::Quick` is installed (`QML_ELEMENT` / `NveSurface` in QML module `Nve 1.0`):

- Consumes NVE's flat 64-byte `NveSceneView` directly onto Qt 6's hardware-accelerated RHI Scene Graph (**Metal** on macOS, **Vulkan/OpenGL** on Linux, **D3D11/12** on Windows, Software for offscreen CI).
- Builds a retained `QSGNode` tree (`NveQtSGBuilder`) using `QSGTransformNode`, `QSGOpacityNode`, `QSGClipNode` (hardware scissor for rects, stencil geometry for rounded rects), `DrawTriangles` rounded-rect/border geometry nodes, and generation-tracked HiDPI `QSGTexture` text caching (`NveQtTextCache`) so unchanged text never re-rasterizes.
- Dispatches press, wheel scroll, focus/blur, and text input via zero-copy `NveDirectEvent` and supports live `geometryChange`, `replaySnapshot` / `saveSnapshot`, and atomic `hotReload`.

### 2. Retained `QWidget` Adapter (`NveQtWidget`)

- Embeds NVE inside any existing `QWidget` application via `RetainedViewReconciler<QWidget*, QtViewAdapter>`.
- Maps primitives to antialiased `NveQtBoxWidget`, `QLabel`, `QScrollArea`, `QLineEdit`, and `QPainter` `NVE_DRAW1` custom widgets (`NveQtCustomWidgets.cpp`) with Qt Accessibility (`NveQtTextInputA11y.cpp`).
- Multi-window lifecycle handled by `NveQtWindowManager.{hpp,cpp}` (`Qt::WindowModal` + `QCloseEvent::ignore()` close veto).

```bash title="Build, test offscreen, and launch Qt Quick or QWidget mode"
cargo build -p nve-example-kitchen-sink

cmake -S hosts/qt-shell -B hosts/qt-shell/build -G Ninja
cmake --build hosts/qt-shell/build
ctest --test-dir hosts/qt-shell/build --output-on-failure

# GPU Qt Quick mode (omit --quick for QWidget mode)
./hosts/qt-shell/build/nve_qt_shell --quick target/debug/libnve_example_kitchen_sink.dylib
```

## Linux GTK4 Shell (`hosts/gtk-shell`)

`hosts/gtk-shell` targets Linux Wayland/X11 (and macOS GTK4 via Homebrew) using native **Pango**, **Cairo**, and **AT-SPI**:

- **`NveGtkHost`** — Registers a native `PangoLayout` text measurer (`PANGO_WRAP_WORD_CHAR`) into `NativeHostSession` and reconciles native GTK4 widgets:
  - `View` / `Pressable` / wrapper `Text` → `GtkFixed` (`GTK_OVERFLOW_HIDDEN` when rounded)
  - Leaf `Text` → `GtkLabel` (`wrap = TRUE`, `can_target = FALSE`)
  - `ScrollView` → `GtkScrolledWindow` wrapping an inner `GtkFixed`
  - `TextInput` → `GtkEntry` with native IME + AT-SPI accessibility (`NveGtkStyleA11y.cpp`)
  - `SkiaCanvas` & `Image` → Cairo `cairo_t` `NVE_DRAW1` + `GdkTexture` (`NveGtkMedia.cpp`)
- **Scoped CSS** — Applies `.nve-host-<id>-node-<node_id>` rules via one `GtkCssProvider`, guarded with `GTK_CHECK_VERSION(4, 12, 0)` for GTK 4.6–4.24+ compatibility.
- **Multi-window** — `NveGtkWindowManager.{hpp,cpp}` binds `GtkWindow`, `gtk_window_set_transient_for`, `gtk_window_set_modal`, and `close-request` veto.

<Callout kind="info" title="GTK 4.24.2 unmapped widget coordinates">
In GTK 4.24.2, `gtk_fixed_get_child_position` returns `(0, 0)` for unmapped/offscreen test widgets. `hosts/gtk-shell/tests/gtk_shell_test.cpp` reads child positions via `gtk_fixed_get_child_transform` + `gsk_transform_to_translate`.
</Callout>

```bash title="Build, run headless CTest under Xvfb, and launch GTK4 shell"
cmake -S hosts/gtk-shell -B hosts/gtk-shell/build -G Ninja
cmake --build hosts/gtk-shell/build

# Desktop or headless CI (Linux)
xvfb-run -a ctest --test-dir hosts/gtk-shell/build --output-on-failure

./hosts/gtk-shell/build/nve_gtk_shell --dylib target/debug/libnve_studio_workspace.so
```
